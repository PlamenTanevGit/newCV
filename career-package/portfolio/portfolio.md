## About

Senior QA Engineer with 8+ years testing enterprise SaaS and financial-services web applications. Strong manual testing, API validation and regression coverage, backed by automation in Selenium (Java), Playwright and Cypress (JavaScript), and a careful, human-reviewed use of AI-assisted QA workflows. Comfortable in fully remote, Jira-based Agile teams.

- Test design: equivalence classes, boundaries, state transitions, risk-based priorities
- Regression confidence: smoke layer, critical flows, clear go / no-go reporting
- Clear defect reports with evidence and investigation hints
- API and data validation: status codes, schemas, permissions, SQL checks
- Automation that supports manual QA, with CI execution
- Remote collaboration and honest QA status reporting
